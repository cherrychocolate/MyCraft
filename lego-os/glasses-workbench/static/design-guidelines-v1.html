干净黑白，鲜明功能色。

04 / INPUT & PERIPHERALS

触摸、按键与外设，同一套焦点逻辑。

OFN / 四向滑动

上下移动焦点；列表边界时滚动。点击确认；返回沿页面历史回退。横向滑动可用于同层标签，禁止无提示切换不同服务。

可按压滚轴

旋转逐项移动或滚动；按压确认。长按、持续按住与媒体控制作为可配置事件保留，不能假定硬件具备额外按键。

快捷键 / 手势 / HID

快捷功能默认映射主页；手势外设与 HID 统一发送导航、确认、返回等语义事件。实际键码与手势识别待外设适配确认。

焦点示例

OS 焦点 4px 功能橙外描边；悬停不是唯一反馈。Enter / 点击确认，Esc 返回，Home 回主页。焦点离开可视区时应自动滚动进入画面。

扬声器：字幕辅助，明确播放 / 停止。麦克风：先点击录音再请求权限，显示录音状态和最长时长。相机：当前使用样例图与预设结果。陀螺仪：保留姿态事件输入，不预设空间融合、3DoF 或眼动等硬件能力。

虚拟设备控制：摇杆或 W/A/S/D 移动当前界面焦点；方向键上进入控制中心、左进入快捷应用、右进入看板与通知、下进入应用中心。A 确认、B 返回，Home 回主页。滑块按 A 进入调整，左右摇杆改变数值，再按 A 退出。透明掌机是可交互的浏览器设备样机，实际外设仍待适配。
05 / MOTION

动效解释变化，不抢走注意力。

时长用途规则
160ms按钮 / 状态 / 焦点反馈颜色、轻微缩放；不引起重新排版
240ms页面或卡片首次出现位移不超过 16px + 透明度
500ms天气趋势绘制 / 图形介绍一次性；不循环闪烁

缓动统一 cubic-bezier(.2,.7,.2,1)。遵守系统“减少动态效果”；视频不自动播放，切换页面时终止旧播放器。真实外设上的运动舒适度仍需实测。

06 / GRAPHICS & MEDIA

图形要带来信息，媒体要有来源。

天气

条件图标、实时温度、湿度 / 风速 / UV、24 小时曲线、7 天温度范围与日出日落。图形从实际响应计算，缺值显示缺失，不能补编。

课程与待办

课程时间轴、地点图标、进度环、待办勾选。颜色只辅助分组；时间、地点与课程状态仍保留文本。

帖子与视频

列表 16:10 缩略图，详情图集；图片保留描述和原帖入口。提供实际视频流时显示原生播放器；只有帖子链接时明确进入原帖播放。

设计器支持文本、卡片、按钮、矩形、图标、图片、趋势图；本地图片随服务保存，HTTPS 外链需要联网。设计器中的手动图表是设计数据，不能冒充正式服务实时数据。

Reddit RSS 现在解析实际图片，但不保证完整图片与视频。已预留认证 API 的 Token 与数据源选择；票数、视频与完整媒体以对应 API 返回内容为准。敏感媒体不直接显示，加载失败提供文字反馈和原帖入口。

Reddit 官方于 2026-11-10 公告 RSS 将在 11 月 13 日停止支持。RSS 不是长期可靠方案；认证 API 需要用户具备访问权限，当前没有认证凭据时不能宣称已完成认证媒体链路。
07 / STATES & HANDOFF

让每一个状态有出口。

状态必须呈现
未配置具体缺少的参数、配置入口，不显示假结果
加载当前步骤 / 读取状态、等待与可退出路径；避免一直空白
空区分无数据、筛选后无结果与尚未运行
失败实际失败原因、重试与连接校验入口，保留此前成功结果来源与时刻
过期上次更新时间；不把缓存称为实时结果
权限点击后才申请位置 / 麦克风 / 外部授权；拒绝时保留手动替代路径
服务发布发布版本冻结；工作台草稿修改不静默影响 OS 里的版本

现阶段是真实服务调用 + 浏览器 OS 模拟。硬件常驻、系统功耗、真实相机识别、空间能力与外设手势识别仍在后续任务中。30° FOV 的轴向未确定，不把设计 px 换算成已验证视角字号。
