03 · 焦点、阅读与返回规则

  1. 每页定义初始焦点，优先当前核心内容；系统返回、技术刷新与创建入口不应默认排在消费内容之前。
  2. 列表以稳定 ID 和明确顺序导航；网格按行列导航。滚动和 sticky 元素不得导致向下移动回到顶部或循环。
  3. 阅读区、图表组、日程组可以成为一个焦点区域。确认进入阅读模式，上下按页/段滚动，返回退出；不要把每段文本变成按钮。
  4. 全局语音球及系统状态有独立通道，不夹在应用列表与阅读区中抢焦点；鼠标仍可直接点击语音球。
  5. 返回恢复原条目、滚动位置和筛选条件。刷新保留稳定条目焦点；条目消失时选相邻条目，不跳到刷新按钮。
  6. 滑块确认后进入调整；方向改变值；确认提交，返回取消本次调整。保持清楚的调整态反馈。
  7. 普通通知不抢焦点；模态确认约束自己的焦点，退出恢复发起位置。禁止嵌套模态链。
  8. 图标具有明确名称；布局和焦点框不只靠颜色区分。焦点、选择、调整、禁用、加载分别有视觉状态。

焦点组件契约：浏览、激活与编辑分离

基础原则参考Android TV方向导航与W3C APG Slider。APG在滑块已获得键盘操作权时使用左右改变数值；Lego OS额外定义“确认进入调节”，用于四向键同时承担页面导航的设备。这是项目的控制权切换策略，不声称所有平台都要求这一阶段。

状态输入职责反馈与退出
鼠标悬停仅指向，不改变值、不进入编辑弱反馈，不能和键控焦点同样醒目
浏览 / 聚焦四向导航，确认才激活；聚焦音量不等于调整音量单一焦点边框；滑块可显示“确认后调节”
调节中左右按步长改变；上下不切走、不偷偷提交；确认提交明确“调节中”与键位；返回还原进入前数值
阅读中上下滚动当前阅读区；返回退出到区域焦点保持当前区域，不跳到系统浮层或切换应用
文本输入输入框按需打开，键盘/语音输入；提交后回内容不得让常驻表单挤占消费首屏

切换页面、系统面板或输入模式时取消未提交调节；持续媒控作为独立输入会结束当前调节后应用新命令。音量/亮度允许本地预览，确认后才保存。焦点、已启用、选中、编辑中不是同一个视觉状态，不能全用白色填充表达。

消费页面的内容预算

  • 默认焦点落在内容或主要任务，管理与诊断进入次级菜单。
  • 视频列表每条内容一个焦点；收藏/关注放在详情。顶部只保留紧凑标题、搜索和更多。
  • 来源与缓存说明仍可查看，但发布时间、API名称、额度和调试状态不常驻占用首屏。
  • 看板默认展示已Pin组件，布局编辑在更多选项中；不擅自改变用户勾选。
  • 刷新保留内容，进度不插入大块区域推移页面；失败才出现必要的恢复提示。
  • 控制中心使用紧凑、可见的常用控制项，不展示“DEVICE / CONTROL”、模拟网络说明或没有活动媒体时的测试音轨。

04 · 表盘模板是一套槽位系统

标准模板定义位置、支持的组件 family、阅读顺序、焦点顺序、唤醒/简视状态以及密度预算。橙框仅为编辑器槽位示意，正式表盘不显示空槽边框。模板类型、组件类型与数据来源三个维度独立组合。

T01 极简时间时间＋可选行内槽
T02 下沿信息带时间＋底部单条摘要
T03 双行简视两条独立行内信息
T04 双圆仪表两个小型数值或进度槽
T05 日程主导近期事项＋辅助指标
T06 角色伴随小型角色＋可选摘要
T07 左右分区时间与侧边信息列
T08 四槽模块按需选四槽，默认少量点亮
T09 专注活动单一后台活动＋返回入口
T10 自由画布可拖拽，保留系统契约

默认简视推荐0–2条同时点亮的信息；这不是全局永久上限。四槽等模板按布局与情境逐项评估，允许配置多个槽位、按条件显示。旧实现“最多2条Pin”只是V1保护条件，尚不能支撑V2模板体系，不能直接冒充V2已实现。

主页不能为了展示所有服务而放满屏幕；上半屏／中部留白与下沿布局均是可选模板策略。自由与实验模板仍须检查内容密度、现实背景、焦点路径、隐私及退出。物理视野的安全阈值需真机验证。

05 · Complications 拼图式创作与服务校对

参考 Apple 的 circular、corner、inline、rectangular 类型，借鉴“槽位限定 family、一个服务提供多个组件、不同组件深链到相关内容、按数据时效更新”的机制。尺寸与环形布局不照搬到眼镜。Apple 旧式模板作为信息表达参考，不能混称为全部现代 WidgetKit 类型。Apple 官方依据

表达 family例子Lego OS 标准约束
行内 Inline下一课时间、温度、未完成数一行可扫读；长内容进入详情
圆形 Circular温度＋图标、进度环、倒计时只有确切分母才用百分比闭环，不伪造完成率
矩形 Rectangular近期日程、简短趋势、摘要少量文本＋一个主图形；不塞完整应用
边角 / 边沿侧边指标、下沿状态适配眼镜矩形与留白，不强迫绕屏排字
动作 / 活动（项目扩展）继续播放、录音时长动作与权限由服务和系统核实；系统隐私指示不由主题绘制

创作路径：选模板 → 展示本机已安装服务提供的组件 → 拖拽到兼容槽位 → 选数据字段/样式/激活目标 → 调整显示条件与刷新策略 → 两种输入模式预览 → 发布固定版本。拖拽发生在工作台；眼镜端焦点编辑提供“选槽→替换→排序/位置预设”的等价路径。

组件注册项必须声明：provider与版本、family、所需字段与类型、可用动作和deep link、权限、刷新/缓存策略、空/错/过期态、隐私级别、可访问名称和焦点角色。运行时核实安装、版本、授权和数据状态；不能只按服务名猜能力。

当前服务 / 能力现在实际具备成为V2组件还缺什么

目前不是完整的 Complication marketplace。已有四种文本绑定不等于所有字段、样式和动作都已注册；V2要求先注册数据与动作，再允许AI或用户拼装。

06 · Widget 与独立应用

容器焦点行为内容与跳转
摘要Widget整卡一个焦点，确认进入服务去掉“点击进入”等提示；卡片本身就是热区
聚合Widget默认整卡，必要时确认进入内部操作模式同服务同样式聚合；不同样式可独立Pin；不按每条数据自动生卡
操作Widget少量受支持动作，明确进入/退出内部操作只允许有执行器和回执的动作
独立窗口根页＋详情为主，必要第三层操作主要消费任务；长表单与复杂设置优先工作台
沉浸消费用户主动进入阅读/视频模式可持续消费；不能夺走系统退出与隐私提示

课表标准Widget：Medium显示当前/最近事项，Large独占一行显示今日聚合日程与下一项/进行中标识。用户可同时Pin两种；配置列表必须显示实际尺寸、内容与来源。Widget与表盘Complication共享provider，但布局、信息量和交互规则不同。

07 · 多任务：一个主窗口＋后台活动，不默认多窗口

600×800与约30°对角视场下，默认一次只让一个服务占用主内容区域。任务切换器显示最近使用服务、活动状态及恢复入口；持续活动以小型系统状态提示呈现，不把多个小窗口同时堆在视野里。助手overlay是临时容器，不等于第二个独立前台进程。

状态切换后策略恢复与感知
前台消费保持当前页面和业务状态离开时保存路由、列表位置、筛选、焦点及草稿
保留 / 挂起普通天气、课表、信息流保留结果，不额外启动持续轮询；已发出的有界请求可以完成立即恢复缓存，过期再后台刷新；区分挂起与正在处理
后台执行已发出的有界网络任务可继续；不能重复启动任务中心显示处理中/完成/失败，完成不抢前台焦点
后台持续活动录音、音频播放、导航等须声明能力与权限系统活动指示＋停止入口；音频焦点由系统协调
暂停消费视频离开前台默认暂停，保存进度返回需用户确认继续；网页嵌入播放器不承诺跨重载保活
结束 / 回收用户关闭或资源回收；释放计时器、媒体与订阅缓存业务可恢复；不把“关闭窗口”混称为停止远端任务

浏览器现状：已有osInstances实例、路由/返回栈和缓存；这提供状态保留，不是操作系统级多进程。页面关闭、浏览器挂起、硬件后台保活均不能由它保证。原生外设需Service Host、后台任务调度、持久化、权限与资源配额适配。任务取消必须有执行器支持；仅停止展示不得标注“远端已取消”。

全局抵达策略：常规四空间Home＋方向两步即可；控制中心与任务切换器可从全局快捷浮层进入。短按快捷键保留用户配置，长按快捷键呼出系统面板；触屏外设/鼠标有可见入口，HID可提供等价快捷键。长按必须抑制短按动作，不能先执行截图再开面板。

08 · 字体、图形、光学与动画

设备基准：600×800逻辑画布、对角30°、双目、默认正前方；每眼像素、重叠、精确角偏移、PPD、环境亮度和光学对比度待校准。以下是产品暂定预算，不是通用人因阈值。

项目V2规则
色彩OS黑色不发光基准，主要文字#fff；功能橙#ff4f00用于强调；不是所有卡片都填白色。工作台可用明快领域色。
字号正文32设计px、辅助24、标题40–46、关键数字按组件；小于24的业务文字需审查。桌面缩放后的CSS像素不代表真机视角字号。
间距8px网格；16/24/32/48主要间距；参考左右32px；焦点框不裁切；中文不以点阵装饰字体长篇排版。
层级标题、主体、辅助最多三层文字强调；去除版本号/调试状态/重复刷新占据的消费首屏。
媒体缩略图、图表、时间轴承载信息；图片失败有降级，不补假素材。视频非自动播放。
动画焦点反馈约160ms、页面约240ms、图形介绍约500ms；装饰动画短暂、响应减少动态；不持续闪烁。
现实融合黑色不能遮住现实；亮/暗/复杂背景分别测试；中心留白与点亮区域按模板配置，不能把包围盒比例当视野遮挡率。

09 · 数据、通知与刷新契约

  • 首屏优先显示已有有效缓存。刷新保留内容和操作位置，显示来源时间而不仅是“刚刚读取”。
  • 区分未配置、尚未请求、加载、无结果、无权限、失败、过期、离线；已配置正在搜索不能显示“请配置API”。
  • 信息流必须声明“有限结果”或分页；支持继续读取时返回游标、去重、末尾状态和重试。刷新不保证必然产生新条目，不能伪装成无限推荐流。
  • 通知分普通、重要、紧急；普通不抢焦点，重要轻提示，紧急需系统规则和用户偏好。隐私状态在行为发生时必须可感知。
  • 第三方内容不自动被视为事实；摘录、来源、AI摘要与模拟数据分别标明。
  • 点击动作、语音动作、焦点激活和鼠标激活调用同一个业务Action，不维护各自假的演示路径。

10 · AI生成与发布验收

AI先生成任务、页面/状态图、组件与数据契约、焦点与滚动关系，再生成视觉和动画。对话修改保留稳定ID、锁定层、来源绑定及系统层；不能靠任意HTML覆盖系统框架。

检查产品暂定目标
路径计数分别记移焦M、确认A、返回B、系统切换S、输入T；从明确起点计数。不得只计鼠标点击。
常用短任务建议≤3次确认且≤5次移焦；超过5次确认或8次移焦触发设计复审。超过10次移焦、循环或无出口属于高优先级问题。
长消费阅读时长和逐条浏览不套用短任务阈值；考核找内容、继续阅读/下一条、返回恢复的额外负担。
层级默认根页＋详情，必要第三层操作；例外说明任务原因和恢复路径。
两种输入焦点与光标分别验收；鼠标能点击不能抵扣焦点链路失败；媒控在每种模式不得误导航。
状态与生命周期缓存/加载/空/失败/权限/恢复；任务切换保留上下文；后台活动指示真实且可停止。
发布先静态校验与自动路径检查，再Computer Use走查；实验模板另列；冻结版本并可回滚。

这些数字是本项目的设计预算，不是“所有用户超过N步都无法接受”的研究结论。最终需在真实硬件上对高频任务做成功率、耗时、错误率和主观负担测试。

规则一 · 焦点与光标的共同交互契约

基础输入为上下左右、确认、返回；确认和返回可映射组合手势。Hover 只标记对象，不等于激活，不改变数值，不进入子焦点。

布局未进入对象时对象内部交互
上下瀑布信息流上下切换条目；对象可单击、长按或左右操作禁止条目内部上下滚动、子焦点切换；确认打开 overlay 或子窗口后再进行
上下瀑布 Slides 流对象可单击、长按、上下滑动；页面必须声明上下的唯一归属禁止 hover 内左右／四向交互和子焦点；确认进入独立层级后开放
九宫格全向页面四向归父级网格；条目只允许单击、长按任何方向的组件内部滑动／子焦点都必须先确认进入独立层级

同一方向不能同时驱动父列表和子组件。未定义映射的滑动或长按不执行动作；禁止把所有卡片的方向事件交给内部 HTML 控件。退出子层后恢复触发对象、焦点和滚动位置。滑块确认后获得左右调节权，确认提交、返回撤销；这是明确进入的控件操作层。

光标兼容与无滚轮

鼠标、touchpad、空鼠与光标摇杆共享命中区域和返回栈。光标显示不改变 D-pad 的媒控职责。无滚轮提供拖动滚动、页内上下翻页按钮；光标摇杆抵达上下边缘继续推动时滚动。右键、设备返回键和画面返回入口执行相同的返回语义。Hover 不切路由、不展开详情、不直接调节。

全局快捷 Overlay

指定或组合手势唤醒系统快捷层，提供快捷功能、快捷设置、首页和多任务切换。它拥有临时焦点；关闭后恢复原应用。应用不能覆盖系统返回／Home 和退出路径。

全局信息：Push / 灵动岛 / 通知

即时 Push 进入时临时聚焦通知层，确认进入关联业务，返回关闭，超时后恢复原焦点。通知需要排队、去重并尊重勿扰；输入和调节期间不得丢失草稿。普通后台状态进入灵动岛，不反复抢焦点；通知中心保留记录。刷新成功、版本信息和运行日志不是用户通知，禁止当作 Push。当前网页实现基础临时焦点通知；跨设备推送和中断队列仍需后续接入。
