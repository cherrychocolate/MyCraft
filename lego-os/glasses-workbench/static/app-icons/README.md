# App launcher icon sources

- `youtube.png` is the 144 px favicon served by the [official YouTube site](https://www.youtube.com/s/desktop/c52980d1/img/favicon_144x144.png).
- `reddit.png` is the 180 px touch icon served by [Reddit](https://www.redditstatic.com/desktop2x/img/favicon/apple-icon-180x180.png).
- `weather.svg` is [Meteocons Partly Cloudy Day, static flat](https://cdn.meteocons.com/3.0.0-next.10/svg-static/flat/partly-cloudy-day.svg) by Bas Milius. MIT license included.
- CalendarDays, PanelsTopLeft, Clapperboard and Link2 are from the [Lucide](https://lucide.dev/) package already used by this project. License included.
