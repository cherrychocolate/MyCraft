# GlassTube · 眼镜播放体验

## 操作和反馈

| 任务 | 界面与控制器 |
| --- | --- |
| 发现视频 | 发现、搜索和本地片库放在顶层。科技、设计和音乐主题读取公开结果。列表使用缩略图、双行标题和频道。 |
| 开始观看 | 搜索成功时焦点进入第一条。确认选中项发起播放。播放器返回状态后才显示播放、暂停或实际失败。 |
| 控制视频 | 横向相邻的七个图形键。播放、前后 10 秒、下一条、字幕、声音和扩大画面。下键进入恢复操作或视频信息。 |
| 保持上下文 | 下一条沿用当前来源列表。返回恢复最初的列表项。个人助手先展示结果，用户确认或明确说开始观看才打开应用。 |
| 登录和受限播放 | 允许嵌入的公开视频可以直接播放。出现验证或限制时，可在官方 YouTube 页面登录或播放，也可以重试或看下一条。 |

参考项目采用紧凑的缩略图行、稳定焦点键和集中播控。Lego OS 复用其交互思路，并通过现有官方视频搜索取得数据。 [GlassTube 参考源码](https://github.com/cherrychocolate/glasstube/blob/main/index.html)

GlassTube 管理界面和方向键焦点，视频由官方 IFrame Player 提供。播放状态、缓冲、错误和自动播放限制根据播放器事件处理。字幕按钮请求开启 YouTube 字幕，切回后使用 YouTube 的默认设置，实际字幕取决于视频的字幕轨。Google OAuth 适用于订阅、片库等账号数据授权。播放器要求的登录在官方页面处理。 [IFrame Player 事件](https://developers.google.com/youtube/iframe_api_reference#Events) · [YouTube 数据授权](https://developers.google.com/youtube/data/guides/authentication)

## 模拟器实测

- 600×800 与 800×600 下，提交搜索后首条自动获焦。按一次确认进入播放器，两个画幅均收到《Me at the zoo》的实际播放回执。
- 控制器实测暂停、前后跳 10 秒、同列表下一条和返回原焦点。字幕开关的请求和播放位置恢复已验证，字幕轨由视频决定。
- 遇到 YouTube 验证时观察到失败反馈，控制器可以继续选下一条。官方页面入口保留供登录或继续观看。
- Kai 用真实搜索在对话中给出结果列表，收到「开始观看」后才进入 GlassTube，播放器确认开播。
