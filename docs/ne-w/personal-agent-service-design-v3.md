## 一、服务设计原点、硬件基线与核心原则

### 1.1 已锁定的硬件、全球外设开放原则与三端分工基线
- **主载体**：`600 × 800` 逻辑画布、双目全彩光学透视光波导眼镜（对角 30° FOV，默认正前方，纯加光显示），具备与智能手机同等的全面传感能力（摄像头、多麦阵列、IMU、定位、环境光与接近传感、蓝牙/Wi-Fi/近场通信）。
  - **硬件人因与全球合规底线（经海内外 10 大人群审计补齐）**：整机重量目标 `<= 40–45g`（亚洲窄鼻梁与妆容友好）、支持近视/老花/渐进多焦点镜片无感配镜及基础头盔兼容、具备户外正午强光与进隧道明暗切换安全可见性、地铁/室内强光下**正面防漏光与防彩虹纹**、全天间歇使用续航配合快充盒撑满 `10–14 小时`；摄像头配备**肉眼远距可识别的物理机械遮光片（Mechanical Shutter）**与物理断麦开关（既满足考场/敏感场合，也化解欧美/日本日常通勤的偷拍戒备）。
- **开放外设原则（BYOW · 不抢手腕）**：
  - 标配/高阶推荐外设为**肌电手环（EMG Band）**（极细无屏腕带/藏袖或饰品化形态、防汗防水、续航 `>= 5–7 天`），兼具微手势盲操、腕部生理感知与离镜独立兜底；
  - **全球化开放兼容**：在欧美/日本等 Apple Watch、Garmin 与机械表高渗透市场，**不强制绑定专有手环**——系统一级原生适配 Apple Watch（Double Tap/震动/HealthKit/SOS）与主流智能手表，并保证**纯眼镜（镜腿微控 + 语音）+ 手机**即可 100% 跑通核心闭环；湿手/手套/长辈场景支持降级为实体键或免按语音。
- **三端刚性分工原则（按物理摩擦最低分配，补齐免手音频与离线兜底）**：
  - **眼镜**：承接 **`<= 10–15 秒`** 的第一视角采集、信息过滤提示、抬头引导与临界兜底；内置**弱网/真离线端侧包**（支持欧洲铁路隧道与山地徒步时的离线导航、离线多语种翻译与离线票据卡包）；
  - **腕部外设（肌电手环 / 兼容手表）**：承接隐蔽微交互、生理 × 情境注意力总阀门，以及离镜时的独立提醒与紧急呼救；
  - **手机伴侣端与音频兜底**：复杂多栏对比、账本与交易归手机端；但在**开车、骑行、抱娃或学生防分心**等不便掏手机的场景，超过 15 秒的内容提供**「30 秒定向语音核心摘要兜底」**，不强行逼用户掏手机。

### 1.2 三条不可动摇的服务设计铁律
1. **隐私不是“不使用数据”，而是“让别人相信你的使用”**：
   - 不应因畏惧隐私而将 Agent 阉割为不敢用数据、不敢记事的浅层问答器。真正的信任来自**可验证的数据去向、完全站在用户一侧的利益中立、每次用数据都带来一眼可见的回报、以及严格遵守当地法律合规围栏**。
   - 诚实披露算力与存储边界：原始音画默认在端侧芯片做瞬时处理；需云端复杂推理的内容仅上传脱敏必要字段至用户私有加密通道，绝不用于公有模型训练或广告流转；欧美区支持 GDPR/CCPA 分项明示授权、本地数据驻留与一键数据可携带导出。
2. **既做“防御减负”，更做“促进丰盈”**：
   - 人类需求不止于“省心、体面、不被坑”（预防定向），还包含**自我效能与心流启动、情绪安抚与低负担陪伴、社交从容连接、以及灵感创作与好奇探索**（调节与促进定向）。如果系统只做防御止损，没出事时用户就感受不到存在感；只有防御与正向体验双轮驱动，才能形成真正长期的情感依恋与高留存。
3. **尊重“千人千面”的心理偏好与动态情绪状态**：
   - “克制低打扰”是一种风格偏好，不是所有人的唯一解。系统必须基于用户的稳定心理特质与实时情绪状态动态调整交互负荷、语气、主动性与深化节奏，绝不用一套“理智克制型模板”套所有人群。

### 1.3 定制服务的职责规则

**设计单位。** 一项个人服务由“本人希望持续取得的进展、愿意交出的责任、留给自己的部分、允许使用的输入、处理方法、可核对的结果、调用与结束条件”定义。一次事务有自己的完成状态；事务结束后，经本人确认的方法可继续适用于下一件事。享受探索、提高独立能力、把更多时间花在喜欢的活动上，均可成为进展。

**三种启动依据。** ① 本人调用已经建立的服务，直接履约。② 已约定的时间或条件发生，按授权履约，未约定的情境信号本身没有启动权限。③ 本人要求改进，或使用中反复出现现有职责覆盖不了的阻力，在相关对话内进行一次服务升级协商。用户拒绝后继续履行原约定。原则适用于所有人；交付内容、承担的责任、频率与渠道由当事人决定。

**价值校验。** 建立核心服务前，查清用户已经付出的时间、金钱、注意力，或因摩擦放弃的有价值活动；记录现有替代办法和其不足。分别比较服务本身的增益与眼镜相对于手机的增益。兴趣探索允许低成本试用；单次满意只支持本次结果。

## 二、用户使用服务全路径：从首次接触到长期注意力托管

真正的个人 Agent OS 不是靠开机一次问卷就“懂你”，而是通过**四个递进阶段**，用高频小胜攒出信任、自然引发用户越说越深，最终承接用户长期需要被托管的注意力，形成离开它就会明显感到生活变重、变烦的不可替代体验。

```text
首次接触：形成可试用的责任约定 → 初期使用：第二个真实事项沿用约定
长期托管：可查、可改、可退出   ← 持续深化：原服务经本人同意升级
```
阶段中的日期是研究观察窗。进入下一阶段取决于下文的证据。

### Stage 0 · 首次接触：识别持续需求并建立首项个人服务


#### 为什么传统冷启动方案全都会失灵？
1. **授权导入过往数据（不可行）**：跨平台无标准接口、用户 Day-0 不会交出全量历史隐私、海量无结构化数据在 60 秒内根本算不出精准首发点；
2. **纯开放式自由聊天（易冷场）**：对陌生设备说“聊聊你自己”，大多数人只会敷衍“没啥事”，不知道设备能干嘛；
3. **静态人口标签勾选（严重失真）**：同样 25 岁或 35 岁，一个正在落地英国留学办医保租房、一个正在冲刺项目或带新生儿——**决定用户此刻最愿把注意力交出来的，不是静态职业标签，而是他「当下正在经历的生活章节（持续性关注点）」或「眼前最急迫的 1 件事」**。


#### Setup 与 First Contact 的分工

1. 手机完成语言、地区、配对与网络设置，支持亲友代配。本人可指定已有 Agent 或从零开始。合焦、基本输入与数据去向说明按 1.0 的轻量 Setup 执行。手机 60 秒与戴镜 90 秒作为流畅度测试预算；计时分别记录，发现已有资料足够时直接试做。
2. 先接住本人表达。可以说、输入、出示一份本人选择的材料，或从具体生活情境辨认困扰。以下六类沿用为研究和举例素材，允许交叉、跳过或补充。

     - **A. 刚进入新环境 / 新阶段**（刚留学、外派/搬新城市、新入职、刚退休、刚生娃）
     - **B. 正在打一场持续攻坚战**（考研/考证/学外语、减脂/康复训练、冲刺重要项目/找工作、戒拖延）
     - **C. 扛着一摊多线并发的日常责任**（管家庭大账与生意/工程、带娃+家长群+家务、高频出差见客户、户外跑单）
     - **D. 盯紧一笔钱或一次重大决策**（盯投资/宏观逻辑、买房/装修/买车、办签证/医保申诉、筹备全家出游）
     - **E. 身心在高压或过渡期，需要稳住节奏**（术后/慢病康复、高压焦虑失眠、独居情绪疲惫、银发独居生活）
     - **F. 生活平稳，想把时间花在更值得的探索与表达**（看展/旅行/美食探店、摄影写作灵感、兴趣精进、拓展社交）
     - **⚡ 快速通道：眼前正有一件最急的事**（如明早赶跨国航班、手头有份看不懂的外语/合同单据、正要打一通扯皮客服电话）→ 先处理当次；本人愿意且存在持续机会时再约定跟进。


#### 服务挖掘器的通用决策规则

| 规则 | 输入与判断依据 | 应执行的动作与退出条件 |
|---|---|---|
| D1 提取证据 | 将用户明说的目标、实际发生的事、现有办法、明确偏好与系统推断分开。出现职业、国籍、年龄或情绪线索时，只用来理解语境。 | 有明确指示就沿用；缺少细节时只补影响下一步的事实。不能用身份替本人决定需求。 |
| D2 上溯与反证 | 从最近事件追到直接后果，再到本人希望获得的持续进展。至少考虑另一种会导向不同服务的解释；表达已经足够明确时内部完成比较。 | 选一句能区分两种解释、披露成本最低的问题，或交付一个可纠正的小结果。把本人否定的解释移出候选。 |
| D3 检验持续性 | 依据既往重复、未来明确机会、长期暴露的低频风险，或本人要持续取得的正向结果。 | 聚合共享同一责任的不同事务。孤立急事先办当次；有一次近期待验机会时可限期试用；只有真实跨事件兑现才能记为已验证持续。 |
| D4 处理多个需求 | 分别判断每个需求的进展与职责。两个需求若需要相反的介入时机、权限或结束条件，分开记载。 | 先完成本人最看重且 OS 可兑现的一条。有共同目标的能力可组合；其他候选只有经本人同意才保留。 |
| D5 最小披露 | 用户拒绝输入、表达简短或不能出声时，检验匿名转述、公开材料、本人选段、静默输入能否保留闭环。 | 选最少数据即可试做的路径；拒绝某权限后重新计算可行性。用户结束时停止；纯样例只能验证能力。 |
| D6 需求与能力分别过门 | 需求端要有本人辨认的进展、现实成本或机会、下次用途；能力端要有可取得的输入、可执行动作、交付凭据、回写方式和失效交接。 | 需求明确而能力不足，缩小职责或交给适当渠道；能力可用而个人证据不足，只试做。两端均通过且本人同意才开通指定范围。 |
| D7 约定执行权 | 明确谁做、谁核实、谁有最终决定权，区分“已准备、已提交、对方已确认、本人认为办结”。 | 让本人改正交付方式和完成标准。主动提醒需独立的条件、时段和渠道；按需长期服务可直接成立。外部高后果动作遵守 §3.1。 |
| D8 及时停止挖掘 | 已能提供安全且可验证的服务，或再问也不会改变动作，或用户想停。 | 转入履约、仅办本次、等待必要输入、暂缓或未匹配。绝不为提高成功率虚构闭环。 |

**置信判据。** 独立记录需求依据（推测／本人实例／本人确认）、持续性（预期／已有反复／跨事件验证）、履约状态（未核实／试做成功／可持续运行）及授权范围。不得把多项弱证据平均成一个高分。所有尚未知的字段保持未知；用户纠正、授权变化、来源失效都会引起相应维度降级。

**Stage 0 准出。** 对有可服务需求的人，目标是至少形成一项经本人确认、OS 能闭环的个人服务。以一次真输入的试做检验判断，并明确下一次如何使用。对白少、拒绝历史数据的用户采用相同准出标准。以下 1.0 组合为候选示例，具体项数、章节与问答轮数均可变化。

### Stage 3 · 长期注意力托管与“无法离开的服务体系”（Month 2 – Month 12+）

真正让用户长期离不开的，不是封闭生态的数据绑架，而是**把大脑里最耗心力的长期注意力安全托管出去之后，形成的 4 项高复利生活资产**：

1. **跨时空隐性承诺的「外部托管大脑」**：
   - 散落在数月乃至数年里的工程尾款节点、质保到期、保险与会员续费、复查周期与检查单归档、家人重要日程，全部由系统在后台静默守望，只在临界前恰当提醒。**离开这套体系，意味着用户要把几十件随时可能出纰漏的碎事重新搬回自己脑子里硬扛。**
2. **越用越准的「个人判断底线与防坑护城河」**：
   - 系统沉淀的不是无用的聊天流水账，而是经过用户一次次校正的**个人决策标尺**（老王的历史建材单价参考库、投资观察前提、信任与拉黑的信源名单、全家出游与吃饭的真实口味底线）。每一次核验和决策都在让这把尺子更精准，迁移到任何新工具都要重新磨合半年。
3. **生理 × 情境的「默契注意力总阀门」**：
   - 肌电手环与眼镜经过长期磨合，真正摸透了用户何时绝不能被打扰（打球、牌桌、陪家人吃饭）、何时需要踩情绪与体能刹车、何时是背手遛弯派活的黄金窗口。这种“懂分寸的安静陪伴”，是天天靠推送抢注意力的手机永远给不了的。
4. **单边外溢的家庭轻协作与持续进化的能力管道**：
   - 个人主权空间始终对本人绝对忠诚；同时系统能按需把全家出游方案、采购或陪诊备忘一键生成脱敏只读卡片发进微信家庭群（不强求家人买同款硬件），让用户成为家里最从容妥帖的掌舵者；随着人生阶段变化，还能通过服务市场持续吸收新专家管道（能力升级而非折腾 App）。


**Stage 3 准出。** 本人能查明有哪些责任在运行、最近实际做过什么、哪件还在等谁。本人熟练、角色变化或不再需要时，可缩小、暂停或结束服务。退出后在下个原定触发机会核验旧规则已停止。

## 三、服务体验目标标准与 600×800 交互/视觉规范

本章定义支撑上述服务路径的硬性产品与工程目标标准（全面修补了独立审计暴露的 6 处工程冲突）。

### 3.1 服务设计边界标准（含全球合规围栏与全人群审计补全条款）
1. **区域合规硬围栏（Geo-Fenced Compliance）**：
   - 在北美全员同意录音州（如加州 CIPA）及欧盟/英国（GDPR / 德国 StGB §201），**强制默认关闭 M0 60 秒环境音频持续缓冲**，并严禁使用“无灯近场收音规避红灯”；仅开放**单人离线口述（离场后 15 秒 Self-Memo）**或**显性双边同意会议模式**；
   - 欧美区支持 GDPR/CCPA 分项明示授权、本地数据驻留与一键可携带导出，欧盟区职场/教育场景禁用强制性情绪识别；对商业机密/敏感账目全球提供**纯端侧本地运行档**。
2. **权限按需申请与亲情分权代配**：不在开机打包索权；首次触发具体能力时大白话说明回报与去向，允许/稍后/拒绝等权；亲情代配硬锁“只管搭台、永无权窥私、仅危急告警、总开关归本人”。
3. **高危外部动作人工闸门 + 唯一保命例外**：付款、对外发消息、修改/删除长期台账、对外共享必须人工确认，严禁倒计时自动同意；**唯一保命例外**：检测到**老人跌倒或剧烈碰撞且 30 秒呼叫无响应**时自动呼救预设紧急联系人或急救电话（按区域合规提供对应医疗/应急免责披露）。
4. **海内外分层生态接入与轻量协同回执**：海外优先走 **OAuth 官方 API 直连**（Gmail / Google Calendar / Outlook / Slack / Open Banking PSD2 & Plaid）跑通全自动闭环；国内封闭生态（如微信群）诚实采用「系统通知栏只读提取 + 一键转发给 PA 助手 + 草稿接力」；发给家人的协作卡片附带**轻量“已看/已办”回执**。
5. **物理可见隐私与免社死捕获**：镜框摄像头配**肉眼远距可识别的物理机械遮光片**；视觉拍摄严守不可隐藏物理红灯，仅做单帧拍物/拍单据/导航；商务/问诊长对话提供**离场后 15 秒极速口述结构化归档**。
6. **健康非诊断红线与防漏服闭环**：生理感知仅作趋势参考、体能刹车与节律提醒，严禁临床诊断；对慢病用药提供清晰的“已吃/未吃”傻瓜确认防重服漏服。

### 3.3 交互基础标准（全人群多态降级 × 三大容器 × VUI × 通知 × 多任务）
1. **肌电手环双态极简交互 + 全人群降级模式（废除反人体工学无名指手势）**：
   - **默认双态机（0 误触 + 3 动作）**：
     - *休眠锁定态*：屏蔽单捏与四向信号，仅响应 `侧键按住即说（Push-to-Talk）`、`拇指+食指双捏（唤醒 8 秒交互态）`、`侧键双击（静默触发 M0 事后 60 秒回溯，替代易误触的无名指轻捏）`；
     - *交互激活态（8 秒有效，操作续期）*：`轻捏`（确认 / 切入灵动岛）、`单轴左右微拨`（切卡/选项）、`拇指+中指轻捏`（逐层返回/退回休眠）、`侧键短按`（呼出卡片菜单）。
   - **四大环境与人群自适应降级通道**：
     - *绝对静默模式（图书馆/宿舍/谈判桌）*：全程闭嘴纯手势走完查词、切卡、确认待办；
     - *免手高噪模式（开车/骑行/抱娃/湿手/戴手套）*：支持高抗噪语音直唤 + 轻点头确认 + 30 秒音频摘要播报（不强推手机）；
     - *长辈极简无障碍模式*：大实体键一键说话 + 语音优先播报 + `>= 32px` 超大关键字视图，不要求复杂捏合；
     - *离镜兜底模式*：摘下眼镜时，手环独立承接定时提醒、轻震与跌倒 30 秒无响应自动呼救。
2. **三大容器单轴焦点边界与无滚轮光标兼容**：
   - *上下瀑布信息流*：单轴上下切卡，禁止卡内上下滚或切子焦点，卡片操作归于 `侧键短按` 或进二级 Overlay；
   - *上下瀑布 Slides 流*：单击展开 + 上下整帧阻尼吸附翻页，禁止 Slide 内左右/四向切子焦点；
   - *九宫格全向页*：`600×800` 单页上限 `2×3` 或 `3×3`，禁止格内任何方向滑动；
   - *无滚轮光标兼容*：按住左键直接推拉滚动 + 清晰边缘翻页按钮（70% 步幅）+ 右键即返回，禁用无提示边缘悬停自动乱滚。
3. **语音交互与智能来电代接标准**：侧键按住即说 + 回答后 6 秒免按追问窗口；紧凑双编码状态点 + 中文短标签；**150ms 内随时打断**；金额/健康/嘈杂场景自动降级为「极简提纲 + 镜内选项胶囊」。AI 来电代接采用**意图识别（防误杀陌生新客户、面试官、快递员）+ 实时字幕 + `<=500ms` 一捏无缝抢接**，不按通讯录一刀切挂断。
4. **三级防打断通知门控 + 高后果复核兜底**：一级静默入箱；二级灵动岛顶部偏右 2 秒缓入、停留 5 秒收拢且**绝不抢夺当前焦点**；对**高后果防漏事项（学校通知、客户催单、服药、应收尾款）**，若 5 秒未看绝不静默吞掉，而是自动沉入**晚 8 点/早 7 点“卸载大脑复核清单”**二次兜底；三级仅限预设家人紧急来电/出行临界/资金安全/跌倒告警，手环双短震 + **1.2 秒防误触锁**。
5. **后台多任务与跨时空回炉标准**：前台严格单视图；后台支持 0 像素常驻轻守护管道、异步长任务（强制支持**暂停 / 取消 / 恢复 / 核查信源**）以及**跨时空主动回炉**（如见客户前 3 秒浮现人脉前情卡、排队走路时自动滚 3 个生词闪卡）。

### 3.4 全彩光波导视觉、多语种排版与审美分级标准（600×800）
- **纯加光物理与全球环境验收**：纯黑 `#000000` 即完全透明，严禁毛玻璃与全屏压暗罩；采用有界微加光轮廓容器，除明亮窗边/杂乱室内/暗房三衬底外，真机须通过**正午强光可读性、进出隧道防致盲切换，以及地铁/室内强光下正面防漏光与防彩虹纹**验收。
- **分语种自适应排版（废除按中文 14 字一刀切）**：
  - *中文方块字*：辅助元信息 `20–22px`，主交互与字幕 `24–28px`（单行 `<= 14` 字），主页时钟/高危/长辈模式 `32–64px`；
  - *日韩假名与拉丁语系（英/德/法）*：按字符宽度动态适配折行与行高（主字幕 `22–26px`，最多 2 行语段边界断句），避免外文实时字幕疯狂截断。
- **双视觉审美档位**：提供**「极简高审美细腻视图」**（面向年轻/日欧高审美用户，极细发光边、高留白、克制冷暖中性光）与**「长辈/户外高对比大字视图」**（`>= 32px` 关键字、中粗字重）两套主题标准；常规状态 80% 像素保持暗态不发光。

### 3.5 用户心理偏好 × 动态情绪状态双层适配模型（零问卷无感校准）
为避免用单一“理智克制型模板”服务全人类，系统在 M1 热状态表中维护极简心理适配模型（严格 **`<= 150 Tokens`**）：
1. **五维稳定心理偏好光谱（Trait）**：
   - `关系距离`（冷峻工具 ↔ 默契搭档 ↔ 温暖陪伴）；
   - `放权控制欲`（事事确认 ↔ 边界授权 ↔ 全权托管）；
   - `主动性阈值`（高敏低打扰 ↔ 情境触发 ↔ 主动启发）；
   - `反馈风格`（直给结论 / 逻辑拆解 / 情绪共情）；
   - `外部脚手架需求`（高自律防催 ↔ 轻防遗忘 ↔ 强微步陪跑）。
2. **五类实时动态心理状态（State，决定当下系统策略覆盖）**：
   - **焦虑过载态**：强制收拢为单行/单动作（`<=1` 选项），先稳情绪再给最小可执行步，**关闭一切深化钩子**；
   - **心流专注态**：0 像素静默，仅保留开启后的手环无感节拍陪跑；

   - *闲暇探索态*：本人愿意探索时可承接其兴趣；提出升级仍须满足 Stage 2 的依据。

   - **社交戒备态**：禁止语音外放，仅手环暗震与极简无隐私暗语；
   - **低能疲惫态**：晚间未完成复核清单自动延期至次晨（防羞耻反扑），提高省力代办与零指责安抚权重。

3. **校准规则**：Setup 的偏好设置和本人的明确表达作为初始依据。Stage 1 的打断、关闭与沉默只提出待确认解释，不能据此开通服务或推断稳定人格。本人当下表达优先于历史推断。Stage 2 可在手机端查看、改写或清除“相处默契”。

## 四、底层支撑架构：8 大原子层与 M0–M4 低边际成本记忆模型

承接 `MyCraft` 8 大原子能力体系（`I/P/F/D/C/A/O/G`），并通过五层记忆收敛解决“单用户深度使用越久、AI 上下文成本越高”的商业死穴：
1. **M0 端侧 60 秒瞬时感官环**：内存滚动覆盖，零落盘零上云；仅主动触发回溯才抽取结构化核对点并销毁原声；
2. **M1 定长热状态键值表（`<= 800 Tokens`）**：偏好、盯盘底线、复查与账期覆盖更新，用 10 年体积恒定；
3. **M2 分域闲时蒸馏摘要（每域 `<= 1,200 Tokens`）**：闲时低成本批处理压缩流水为认知增量；
4. **M3 窄域按需挂载**：聊导航/球局时不加载财务与工程记忆，降 80% 无关消耗且防串味；
5. **M4 高频能力固化（由思转行）**：高频核账、盯盘、早晚简报跑顺后固化为确定性脚本 + 接口管道，**用户用得越深、单次服务平均算力成本反而越低**。


### 4.1 服务挖掘器与履约运行时

LLM Skill 读取当前对话、本人选定材料与已确认的相关状态，提取 D1–D8 的证据。JTBD 用于辨认生活进展，阶梯访谈用于在事件与价值之间往返，COM-B 用于区分本人想做的行为受能力、机会还是动机影响。模型生成竞争解释与鉴别问题；能力目录返回本地区、本设备、当前权限下真实可用的输入、操作、结果和故障路径。规则校验授权与闭环，历史相似度只供内部检索。JEV 的含义与接口待明确。

**交给运行时的服务定义。** 生活目标、用户证据、本人保留的职责、PA 承担的职责、接受的输入与来源、按需调用方式或获准触发条件、交付物、完成凭证、当前状态、纠正与退出路径。每个长期事实标注来源、范围、有效期和确认状态。按域加载 M1–M3；已稳定的重复操作可进入 M4。在范围内直接履约，发生未覆盖需求或本人要求调整时才重新调用挖掘器。更改规则时明确是否作用于旧事项；重试同一输入或回执时只更新一次，避免重复提醒或重复执行。

## 五、体验交付范围与 3.0 验收标准

本章以 1.0 的五个原型模块、范围边界与四维门禁为底稿。设计与文档承载于 MyCraft；所有能力演示须注明真实接入、人工模拟或样例。

### 5.1 交付 必须端到端跑通的 5 个核心体验模块（In-Scope）

以 Persona 01「老王」为默认核心体验主线（保留通用/切换模式）：

1. **首次接触与首项个人服务**：手机轻量就绪 → 戴镜合焦、基本输入与数据去向说明 → 按 D1–D8 试做并形成责任约定 → 进入日常。无素材可体验样例；没有本人证据时不计授托。必须演示第二次本人调用如何复用约定。

2. **日常 4 条核心体验切片（明确区分 PA 主动代理 vs HUD 辅助）**：
   - *切片 A（PA 通信守门员 — 骚扰拦截 & 忙时 AI 代接 + 随时本人抢接）*：演示老王打球/开车时，陌生推销来电被 PA 静默拦截，快递/非紧急来电由 PA 按口径代接并在镜内浮现极简实时字幕，支持老王轻捏手环 **0.5 秒切回本人接听**；
   - *切片 B（出行/行情双流）*：下方抬头轻导航 + 侧键按住即说核实财经/头条传言并出 2 行带信源结论；
   - *切片 C（随口记事 + M0 60 秒回溯）*：手环静默触发 M0 回溯截留口头承诺，生成本地可编辑/可一键删除核对单；
   - *切片 D（体面生理刹车）*：模拟运动/压力偏高时，手环私密暗号轻震 + 一瞥 1 行温和提示（不弹窗、不露敏感病词）。
3. **1 条完整的「Stage 2 深化钩子 → 跨端接力」闭环演示**：

   - 沿用老王查自选股、核工程单或筹划出游的切片；本人要求深化，或既有服务反复遇到相同缺口并经本人同意，才扩展责任。后台长任务可暂停、取消、查信源，复杂明细落手机，镜内仅承接已约定的临界提示。

4. **完整 `600×800` 交互与视觉规范兑现**：
   - 严格互不重叠三段安全区、L1 发光 `<= 20%`、全界面 `>= 20px`、肌电手环休眠锁 + 3 动作双态机、三级防打断通知门控、150ms 语音打断与私密降级、无滚轮光标兼容。
5. **透明数据去向与诚实模拟面板（位于体验视野之外的伴侣/评审层）**：
   - 随时可查 M0/本地加密/脱敏推理三类数据流向、逐项撤回权限、切换明亮/室内/暗房与纯黑光学检视、并提供“自动引导 + 随时手动接管”双模式。


### 5.2 交付 明确不做的范围（Non-Goals，防范围蔓延）

- 不做真机固件、真实 BLE/UWB 驱动或真实银行/券商/医疗系统直连（全部使用标注清晰的诚实本地模拟数据）；
- 不在 `600×800` 镜内做象棋棋盘、抖音视频流、多页合同精读或复杂 K 线图；
- 不做全品类空壳应用商店，也不强制模拟全家多副硬件的复杂多 Agent 互联（1.0 仅演示单边生成脱敏微信卡片）。


### 5.3 交付 四维验收准出门禁（全部 Pass 方可交付）

1. **服务体验门禁**：零上下文新体验者走完 Stage 0 后，能在 1 分钟内用自己的话讲清“这副眼镜 + 手环用来做什么、和手机怎么分工”；无说教感、无 Day-0 隐私压迫感。 进一步核查 §2 的四阶段准出条件，尤其是第二次使用时能否直接续接个人服务。

2. **交互人因门禁**：肌电手环双态机 0 手势冲突；三大容器单轴焦点无死锁；通知到达 0 抢焦；语音 150ms 内可打断；无滚轮指针与键盘/手环均可独立走通全流程。
3. **光学视觉门禁**：零不透明黑背板与毛玻璃；`600×800` 三段安全区 0 重叠；L1 待机包围盒 `<= 20%`；全镜内文字 100% `>= 20px`；在三类真实实景 `screen` 混合及纯黑检视模式下实拍截图逐帧通过。
4. **数据与诚实门禁**：零虚构记忆条数、零伪造医疗体征或诊断、零未授权默认开启传感、所有模拟能力在体验外伴侣层如实披露。


### 5.4 服务规则的反例验收

用同一套 D1–D8 盲测不同身份、语言、表达意愿与社会条件；记录真实机会数和实际结果。下面是改变一个条件就应改变决策的最小用例。

| 输入变化 | 应通过的判断 |
|---|---|
| 身份相同；一人想少漏手续，另一人想独立参与课堂 | 产出不同进展、责任和验证条件。 |
| 目标相同；一人提供可持续读取的来源，另一人仅口述一段 | 前者实际核验后可约定监测；后者只处理转述与后续反馈。 |
| 低披露，但愿意匿名试做；或明确拒绝留存 | 前者依证据建立窄服务；后者完成当次，不建立持久状态。 |
| 次日用户换说法、换事务但职责相同 | 直接沿用约定，准确更新状态，无需重走发现流程。 |
| 场景相似但无约定或新增需求证据 | 保持待命；本人发起即可使用。 |
| 出现相互冲突的偏好、来源中断、旧规则撤销 | 本人当前明确指示优先；无法履约则交回责任，撤销后停止。 |
